# layouts/

应用布局容器目录，定义应用的整体结构和导航框架。

## 文件

### `MainLayout.tsx`

应用主布局组件，提供：

- **自定义标题栏** - 通过 `TitleBar` 组件提供统一的窗口拖拽与窗口控制按钮，替代系统原生标题栏
- **左侧边栏** - 包含导航菜单（Home, Settings, History）和版本信息；支持折叠为贴边窄条，状态持久化到 `localStorage`
  - 折叠态宽度 48px，导航菜单显示为图标按钮并保留 hover/active 反馈与 title tooltip
  - 折叠/展开按钮位于侧栏右缘中部，独立于侧栏容器以避免被主内容区遮挡或裁剪
- **右侧内容区** - 渲染当前路由对应的页面内容
- **路由导航** - 基于 hash 路由的页面切换逻辑

所有页面组件通过 `MainLayout` 包裹，确保统一的视觉和交互体验。
