# lib/

通用工具函数目录。

## 文件

- `utils.ts` - `cn()`：合并 `className`（`clsx` + `tailwind-merge`）。
- `hotkey-utils.ts` - 快捷键工具：规范化、构建、格式化与校验 Accelerator，并内置系统保留键规则；修饰键按物理键 `code` 区分左右（右 Alt/Control/Shift 产出 `AltRight/ControlRight/ShiftRight` token，可单独作为 PTT 键；组合键中归一为普通修饰 token），Windows AltGr 的合成 Control 按键直接丢弃；F1-F24 与方向/标点 token 与 Rust `hotkey.rs` 解析器逐字对齐（含"纯修饰键只能是单个裸修饰键"预校验），未识别的键返回原始键以触发 `unsupported` 提示而非静默丢弃。
- `tauri-api.ts` - Tauri IPC 桥，挂载为 `window.electronAPI`（与 Electron preload 同形）；`setConfig` 返回 `SetConfigResult`（持久化配置 + `hotkeyRolledBack` 回滚标记），`setHotkeyCaptureActive` 通知 Rust 快捷键录制态守卫，`setOverlaySize` 把 overlay 窗口缩到 HUD 胶囊内容尺寸（`set_overlay_size`，Rust 侧钳制尺寸合法性），`setOverlayPosition(x, y, capsule?)` 把拖拽后的物理像素坐标交给 Rust 做贴边吸附、工作区钳制与持久化（`x`/`y` 为 `null` 表示重置为底部居中默认位；可选 `capsule: { width, height }` 为可见胶囊实际尺寸、逻辑像素，Rust 据此做**半隐贴边**吸附——胶囊中线压在屏幕边上、一半嵌入屏幕，缺省回退按窗口外框吸附的旧行为；**返回值** `Promise<OverlayEdge | null>`——`'left' | 'right' | 'top' | 'bottom'` 表示本次落位已贴边吸附（docked，待机胶囊收成紧凑形态），`null` 表示超阈值仅钳制落位或复位（保持全形），Rust 同时把该结果持久化到 `app.overlayDocked`，HUD 挂载时经 `getConfig` 读回以跨重启恢复形态）。鼠标中键 PTT 设置（`mouse.middleClickPtt`）随 `setConfig` 流程下发、无独立桥方法；悬浮胶囊显隐由托盘菜单直接控制（`app.overlayVisible`），`onOverlayUpdate` 的 `OverlayStatus` 含常驻待机态 `idle`。
- `logger.ts` - 渲染进程日志初始化：转发 `console` 与未捕获错误到主进程日志。
- `stats.ts` - `computeStats()`：合并 Rust 侧独立持久化统计（`StoredDictationStats`，`get_stats` 取数，删除/裁剪历史不影响）与历史实时聚合，计算今日/近 7 天/累计/活跃天数/峰值日；**`stored` 存在时全部字段取自 `stored`**（累计读 `totals`，今日读 `daily[todayKey]`，近 N 天按日历日求和 `daily`），故删除/清空历史后数字不缩水；仅 `stored` 缺失（老版本回退 / `get_stats` 失败）才整体降级为纯历史聚合。`countCharacters()` 按 **Unicode 码点** 剔除空白计数（`Array.from` 拆码点，emoji 计 1），与 Rust `stats.rs` `count_characters` 逐字对齐。`stats.test.ts` 为其回归测试：`countCharacters` 用例是 Rust 单测 `count_characters_matches_frontend_whitespace_rule` 的 JS 镜像（含 emoji 用例），另有 `computeStats` 删除历史后输出不变的锁定用例，两侧口径必须同步改。
- `overlayDrag.ts` - HUD 胶囊「点按切换 / 按住说话 / 拖拽」状态机的纯函数实现（0.5.3 重设计）。会话语义：**轻点 = latch 切换**（松手后录音持续，再点一下 stop 识别）、**按住满 `HOLD_LATCH_MAX_MS` = PTT**、**拖拽 = 只移窗且从不启动会话**。负责 pending → dragging / holding → end 的阈值判定、pointerId 过滤、**手势歧义消除前不启动会话**、双击复位（第 2 击静默 cancel-session）、以及 pointercancel / blur / 看门狗只作用于活跃手势并**豁免已松手的 latched 会话**；另含 `isSilenceAutoStopDue` 纯函数（latched 会话静音自动停止判定，`SILENCE_AUTO_STOP_MS` / `SILENCE_LEVEL_THRESHOLD`）、**贴边紧凑形态词汇** `isOverlayEdge`（docked 判定，invoke 边界脏值一律按「未吸附」处理）与 `DOCK_COMPACT_PX = 32` / `DOCK_TRANSLATE`（紧凑胶囊边长 + 四边贴齐位移类，±16px = 边长/2，把胶囊外缘压到窗口中线 = 屏幕边、整只屏内）。**硬不变量（模块头 REGRESSION WARNING）**：窗口几何在任何手势进行中（pending / holding / dragging）与会话存活期间不可变——命令词汇里**没有任何 resize / 重锚定命令**（0.5.2 的「拖不动 + 闪烁」与 0.5.3 的「按住骤停」都源于手势内 resize 打断指针）。只返回命令描述，不访问 DOM 或 Tauri API。`overlayDrag.test.ts` 覆盖上述全部语义（含「pointerdown 不得启动会话」「拖拽不得 start/cancel 会话」「latched 不被 cancel/blur/看门狗误杀」「window geometry invariant」等回归锁定用例）。
- `useStatFormatters.ts` - 统一的数字 / 时长 / 峰值日格式化 Hook，供主页与统计组件共用。
- `useTheme.ts` - 明暗主题与强调色 Hook：持久化到 `localStorage`，同步切换 `<html>` 的 `.dark` 类与 `data-accent` 属性，并在切换瞬间抑制全局过渡。提供 `ACCENT_OPTIONS` 与 `Accent` 类型供选择器使用。
- `changelog.ts` - 更新日志解析：将仓库 `CHANGELOG.md` 按版本分节，供 `ChangelogDialog` 渲染。
